# TalentBox Product Context

TalentBox is pivoting from a recruiter-facing GitHub sourcing tool into a candidate-first startup hiring platform for Indian tech professionals.

The first public product surface is a beta waitlist landing page.

The platform will help candidates:
- Discover startup jobs from funded Indian companies
- Build a deep AI-powered talent profile from resume, GitHub, portfolio, and voice interview
- Get matched privately with startups
- Receive startup job alerts on WhatsApp
- Keep their profile private and not publicly searchable

Current MVP focus:
- Startup job aggregator
- Candidate signup
- GitHub import
- Resume and portfolio import
- Sarvam voice interview
- Deep candidate profile generator
- Weekly WhatsApp job alerts

The homepage should currently collect only:
- Full name
- WhatsApp phone number

Do not expose old recruiter SaaS positioning on the homepage.
Do not make the product feel like a generic job board.
Do not show public candidate profiles.
