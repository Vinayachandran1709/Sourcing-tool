# TalentBox Design Direction

Design style:
- Premium
- Dark mode
- Minimal
- High contrast
- Startup-like
- Trustworthy
- Clean typography
- Sleek beta waitlist aesthetic

Reference:
- Similar spirit to Storio beta waitlist screenshot
- Dark background
- Split layout on desktop
- Left side: brand, beta badge, headline, promise
- Right side: compact waitlist form
- Mobile: stacked single-column layout

Brand feeling:
- Private talent network
- High-signal startup hiring
- Built for Indian tech professionals
- Not a generic job portal
- Not a recruiter SaaS homepage

Visual preferences:
- Black or near-black background
- Subtle gradients/glow
- White primary text
- Muted gray secondary text
- One accent color: #FF6B35
- Rounded inputs and buttons
- Crisp spacing
- No clutter
- No unnecessary navigation

Landing page requirements:
- Logo/text mark: TalentBox
- Small beta badge
- Strong headline
- Short subheadline
- 3 value points
- Full name input
- WhatsApp phone input
- Join Beta button
- Privacy/WhatsApp consent line
- Success state
- Error state
- Fully responsive
